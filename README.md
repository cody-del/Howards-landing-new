# Howard’s Draperies — Motorized Shades

Standalone motorized-shades landing page for Boulder and the Front Range.

## Netlify

Connect this repository and deploy the `main` branch. The checked-in `netlify.toml` publishes `dist` directly; no build command, dependency installation, Next.js adapter, or Keystatic environment variables are needed.

## Local preview

Run `python3 -m http.server 4319 --directory dist` and open http://localhost:4319.

## Consultation form

The form is a labeled preview and does not submit details. Existing live consultation and phone links are provided.
